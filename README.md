# 澄音 LUME

澄音的动态歌词画面改编自 chthollyphile 的 [Folia](https://github.com/chthollyphile/folia-major)，经 [KONEWS/folia-Lyrics](https://github.com/KONEWS/folia-Lyrics) 接入播放器。播放时的歌词来自用户导入的音频标签、配套歌词文件，或播放空间中分享该曲目的设备。歌词动效、字体、字形数据、界面和音频组件的作者及许可证见[歌词与第三方来源](THIRD_PARTY_NOTICES.md)。

Folia 歌词的渲染、动效和样式设置以上游 Folia 为准；澄音只维护接入本机曲目、歌词和播放时钟所需的适配。引入新的上游改动时，先核对 [Folia 原仓库](https://github.com/chthollyphile/folia-major) 与 [folia-Lyrics 分支](https://github.com/KONEWS/folia-Lyrics)，保留原作者署名、许可证和可编辑源码，再分别验证桌面、Android 与 HarmonyOS。当前内置共用渲染器的来源提交及构建方式见 [folia/README.md](folia/README.md)；本段说明维护原则，不表示已同步上游最新提交。

局域网音乐播放器 0.5.9。Windows、安卓与鸿蒙均可创建、加入和管理播放空间。电脑和 Web 可从电脑或在线手机曲库点歌，Android 与 HarmonyOS 原生播放器可以独立导入和播放手机音乐，也可以自动发现电脑并一起播放左右声道。

Windows、网页与手机默认使用蓝夜配色。侧边栏底部的「外观」可切换本机配色。导航指示块平滑滑动，手机使用实时透镜折射，Windows 使用蓝夜亚克力。按住底部导航可以滑到其他页面，拖动播放进度并松手即可定位。内置三首原创合成试听音乐，不依赖互联网、账号或在线音乐服务。

歌词样式预览沿用 Folia 的两首示例曲目，分别是 Ado 演唱的《踊》和月見ヤチヨ（CV 早見沙織）演唱的《星降る海》。词曲作者、预览数据出处和翻译署名情况见[预览曲目署名](THIRD_PARTY_NOTICES.md#样式预览中使用的两首歌)。

## 安装包

[GitHub 历史安装包归档](https://github.com/KONEWS/Lume/releases/tag/historical-installers-2026-11-22) 收录 `release/` 目录截至 2026-11-22 的 Windows `.exe`、Android `.apk` 和 HarmonyOS `.hap` 安装包。附件名中的 `root__` 代表 `release/` 根目录，其他附件以原相对目录开头；完整原路径、文件大小与 SHA-256 见该 Release 的 `MANIFEST.json`。归档包含各开发阶段的旧包，安装时请核对平台和版本。

## 开始使用

运行 `release/Lume-0.5.9-Windows.exe`。首次启动需要解压运行资源。手机配对、安装和更换皮肤见[手机使用说明](docs/手机使用说明.md)。

1. 点击试听曲目播放，或用「导入音乐」选择本地音频。打开左上角菜单可按专辑、艺术家和文件夹浏览，或在「歌单」新建歌单。「扫描音乐」可查看扫描过的目录、屏蔽或解除屏蔽文件夹。屏蔽包含子目录。默认跳过短于 60 秒的音频，可在本页关闭。手动导入单曲仍可添加短音频。扫描时显示已处理首数。导入时可点「暂停导入」，当前文件或小批次结束后会等待「继续导入」。播放和暂停歌曲可以照常使用。「音乐库」可查看音频总大小、歌词覆盖率及音质分布。「统计」按曲目记录播放次数。
2. 手机和电脑连接同一 Wi-Fi，打开手机澄音。在电脑「播放空间 → 连接设备」选择附近手机的型号，点「邀请加入」。手机点「申请加入」，再在电脑点「允许加入」。
3. 用浏览器加入时，展开「手动连接」，打开列出的局域网地址，输入六位配对码即可控制曲库和播放队列。
4. 要让浏览器所在设备也发声，点击启用声音；在播放空间中分别控制设备是否参与、音量、静音和声道。

Windows 桌面程序承载本地服务，关闭它会断开网页连接。仅关闭控制网页不影响其他仍在线设备。配对会话会随服务重启失效，手机可重新搜索空间并申请加入，网页可使用本次配对码。

局域网访问需要设备处于可相互访问的网络，Windows 防火墙允许此应用在专用网络接受连接；本项目不会自动修改系统防火墙。访客 Wi-Fi、客户端隔离或 VPN 可能影响连接。地址中可能有虚拟网卡，请选实际家庭局域网地址。

在「音乐库 → 手机媒体库」选择在线手机和歌曲。手机只共享已加入澄音曲库的曲目，选中后才传送音频。

## 已实现

- Windows 桌面程序与响应式 Web 页面，共用界面和控制协议。
- 手机提供本机曲库、文件导入、进度控制和切歌。加入空间后可浏览共享曲库并控制播放。安卓默认右声道，鸿蒙默认左声道。电脑生成 48 kHz PCM 音频块，手机提前缓冲，并按输出时钟连续微调采样位置。
- Windows 和 Web 的「播放空间」提供同步节拍和每台原生手机的 ±1000 ms 延迟调节，支持 1 ms 步长；结束节拍后恢复原曲。
- 在设置里导入空间皮肤，桌面、网页和已连接的原生手机跟随配色。
- 三端本机播放器支持内嵌封面和歌词。扫描文件夹时也可匹配同名 .lrc、同名图片或同目录的 cover.jpg、folder.png 等封面。电脑播放栏点击「词」，手机展开播放器后点击「歌词」。
- 播放、暂停、拖动进度、切歌、随机与循环、全组音量和静音。
- 局域网配对、实时控制更新、真实在线设备列表。
- 每个输出端的参与开关、独立音量、静音，及立体声／左声道／右声道／单声道选择。
- 以共同播放时间轴进行实验性多端跟随，断连时停止本机输出，重连后重新对齐。
- 减少透明效果的显示偏好、键盘焦点和响应式布局。
- 三首 60 秒原创合成试听音乐及原创 SVG 封面。

导入会复制所选文件到应用曲库，原文件不会修改。电脑端会自动分批导入，每首不超过 200 MB。能否播放特定编码取决于 Chromium 的解码支持；不支持的文件会显示播放错误。

## 本版边界

- 每个空间由创建它的电脑或手机协调，其他设备可申请加入并管理输出；NAS 挂载、自动主机转移、云盘属于后续工作。
- 左右声道选择是真实音频路由，但跨设备同步仍是实验功能：采用浏览器音频、网络时间估计和播放位置修正，支持听音位置手动校准，未测量两部手机扬声器的实际声学时差，不能据此称为精确的 5.1／7.1 系统。
- Web 和桌面使用相同 Web Audio 播放核心，桌面外壳并非已经实现独立 WASAPI 同步引擎。
- 蓝牙耳机、浏览器锁屏和后台持续播放需要真机测试。系统可能暂停音频，切换输出后可能需要重新启用声音。
- Windows 原生亚克力效果依赖系统版本及设置；网页通过 CSS 玻璃效果保持相同审美。
- 本地 HTTP 面向可信局域网，不提供公网部署入口。
- 当前 Windows 构建没有商业代码签名。

## 开发

完整构建需要 Node.js 24 或更新版本，以及 npm。首次从源码运行时，在项目根目录执行以下命令，准备桌面歌词页及分析模型。

```powershell
npm ci --prefix pc-lyrics
npm --prefix pc-lyrics run models:fetch
npm run build:pc-lyrics
```

```powershell
npm install
npm run dev
```

开发网页地址为 `http://127.0.0.1:5173`；本地音频服务默认端口 46321。

```powershell
npm run build
npm start
```

构建 Web 后启动 Windows 桌面程序；程序自行启动本地服务。如果默认端口已占用，会选择可用端口，以界面显示的实际地址为准。

```powershell
npm test
npm run package:win
```

生成 Windows x64 免安装包。打包应用将曲库保存到 Electron 用户数据目录下的 `library`；源码运行使用项目的 `.lume-data`。退出时保存曲库、收藏、队列及暂停进度。

如需重新生成试听资源：`node scripts/generate-demo.mjs`。

## 结构

- `src/`：共用 React 界面、音频输出和设备会话。
- `server/`：曲库、文件导入、音频流、控制时间轴、配对与设备连接。
- `electron/`：Windows 窗口、桌面桥接和本地服务生命周期。
- `resources/demo/`：内置原创试听音频。
- `tests/`：服务整合测试。
- `PLAYER_VISION.md`：完整产品愿景及后续多平台路线。
