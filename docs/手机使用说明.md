# 手机播放与左右声道校准

## 本机播放

按住底部选中胶囊，向左或向右拖到目标标签。胶囊会先横向拉长，再向上下两侧变宽，松手后回弹并切换页面。

首次使用时，先从「曲库」导入音乐。点按或上滑底部迷你播放栏可展开封面，在播放页下滑可收起。慢拖超过一半后松手完成切换，快速甩动则按甩动方向展开或收起。左右滑可切换封面和歌词，拖动进度条可跳转播放位置。收起播放页后，音乐会继续播放。

在「曲库」可搜索歌曲或艺人、查看收藏，或点「导入音乐」选择自己的音频。安卓记住系统文件选择器授权的音频位置，鸿蒙把所选音乐复制进应用曲库。本机音乐和界面资源均可离线使用。

在屏幕左侧向右拖可打开侧边栏，默认起手范围是屏幕左侧 33%。打开侧边栏的「设置」，再点「侧边栏拖动范围」。在全屏调整页左右拖动红线，即可设置起手位置的分界，左侧灰绿色区域就是可起手范围，可调整为 0% 至 100%，0% 关闭手势，在侧栏上向左拖可收起。侧栏随手指移动，慢拖过半后松手即可完成，快速滑动也可直接展开或收起。左上角菜单仍可打开侧边栏。在「扫描音乐」选择文件夹后，应用会查找子文件夹中的音频，然后逐首显示处理进度。在「歌单」新建歌单、勾选歌曲并保存，可在本机按歌单顺序播放。「音乐库」显示音频文件总大小，以及歌词和音质的占比。扫描时会匹配同目录的同名 LRC 文件，并读取支持的内嵌歌词标签。「统计」按曲目显示从本版开始记录的播放次数。暂停后继续和拖动进度沿用同一次播放。侧栏底部可打开播放空间。

## 加入电脑

1. 电脑运行 `release/Lume-0.5.9-Windows.exe`。安卓使用 `release/Integrated-20261121/Lume-Android-0.5.21.apk`，鸿蒙使用已签名的 `release/Integrated-20261121/Lume-HarmonyOS-0.5.21.hap`。分轨需要电脑上的 FFmpeg。
2. 两部手机和电脑连接同一 Wi-Fi 或热点。打开手机澄音并停留在本机播放模式，电脑「播放空间 → 连接设备」会自动列出附近手机的型号。电脑点「邀请加入」，手机点「申请加入」，电脑在同一窗口点「允许加入」。也可以从手机发起连接。在手机「播放空间」选择自动出现的空间，在电脑点「允许加入」。网络刚切换时可以点「重新搜索」。
3. 如果路由器屏蔽了局域网广播，可展开「手动配对」，填写电脑显示的地址和六位配对码。手机搜索空间使用 UDP 46322 和 46323，电脑搜索手机使用 UDP 46324，音频和控制走电脑界面显示的 HTTP 端口。
4. 在手机「空间」顶部可查看本机型号。加入后，手机的「曲库」显示空间音乐；任一端选择歌曲、暂停、定位或切歌都会控制房间。离开空间可切回本机曲库。

## 用任一设备主持和管理空间

电脑启动澄音就会创建空间。安卓、鸿蒙在「空间」点「用本机创建空间」，创建后保持应用运行。手机或电脑均可从附近的空间列表选择房间。电脑在「连接设备」点对方的「加入空间」，进入来宾窗口后申请加入或输入主机配对码。加入后，成员可以批准其他设备的申请。

在手机「空间 → 输出设备」选择「本机」或另一台在线设备，设置声道、输出延迟、独立音量、静音及参与播放。电脑在「播放空间」操作相同控制项；加入手机创建的空间后，在来宾窗口使用「输出设备」。各端使用 0.5.5 或更新版本。

## 从电脑播放手机上的音乐

在华为或一加的本机曲库导入音乐，让手机加入同一个空间。在电脑或 Web 的「音乐库 → 手机媒体库」选择来源手机，点击歌名。电脑收到选中的音频后开始播放，两部手机继续使用原来的声道和延迟。两部手机有同名歌曲时，可通过来源选择框区分。

手机共享歌单后，电脑按需临时缓冲单首音频，最近八首可在本次会话内重播。每首最多 500 MiB（524,288,000 字节，含上限）。首次播放需要等文件传完。音源离开后，其目录会从电脑消失，已经缓冲的歌曲可以继续播放。关闭 Windows 播放器会清理这些临时文件，原曲保留在手机上。

在「我的设备」中向已授权的设备发送歌曲时，三端也使用这个上限。接收方点「接收并保存」后，传完的歌曲会加入本机曲库，可离线播放。

## 边听边校准

在电脑「播放空间」确认鸿蒙分到左声道、安卓分到右声道。只听两部手机时，关闭 Windows 桌面的「参与播放」。先点「试听同步节拍」，坐在实际听音位置，听两边同时发出的短音。

先固定一部手机。如果左边先响，就增加鸿蒙的「输出延迟」，先按 +10 ms，接近后再用 ±1 ms 调整。右边先响则调安卓。数值范围为 −1000 到 +1000 ms，正值使该手机晚响。点「结束节拍 · 返回音乐」恢复原曲，也能在听音乐时直接调。数值按手机安装实例保存在电脑，退出和重新加入后会沿用。更换蓝牙耳机、扬声器或听音位置后，可以重新试听。

电脑把音乐分为每块四秒的 PCM，两端提前载入随后几块。输出按音频硬件的采样位置和电脑时间轴对齐，小幅变化连续修正。设备中断联网超过缓冲时间仍会缺音。实际扬声器到耳朵的时差由听音校准补偿。

## 外观和构建

Windows 或 Web 的「偏好设置 → 空间皮肤」可导入 `海盐.skin.json`。配色随空间更新；手机界面随安装包提供，播放由各平台的原生音频引擎负责。安卓在 `mobile/android` 构建，鸿蒙在 `mobile/harmony` 构建。鸿蒙新工作区先从 `build-profile.example.json5` 创建本地 `build-profile.json5`，在 DevEco Studio 为目标真机设置自动签名。当前鸿蒙包已为本机连接的 Mate 70 Pro 签名。

桌面、网页和手机版使用 [Lens 透镜设计系统的 fork](https://github.com/KONEWS/design-systems) 中的 WebGL2 折射渲染器和弹性手势。上游版本为 `7a424c9`，MIT 许可证随安装包保存在 `player/lens/LICENSE`。
